## What this is

Karim's personal hub: the one address every LinkedIn post and episode links to. It says who he is, holds a project page per app, runs the email signup that doubles as each app's waitlist, and grows a "how I built it" section. It belongs to no single project. Sila, the demo Islamic bank in `karim-belhadjali/islamic-bank`, is the first project page.

The goal and the stages live in the pinned issue [Roadmap: hub](https://github.com/karim-belhadjali/hub/issues/17). Each stage gets one wayfinder map, attached to the roadmap as a sub-issue. Sila's plan is in [Roadmap: Sila](https://github.com/karim-belhadjali/islamic-bank/issues/21).

Start any session by reading the roadmap, then load the open issue labelled `wayfinder:map` and read its Notes. When a map reaches its destination, close it, tick it on the roadmap, and chart the next stage with `/wayfinder`. Change the plan by editing the roadmap, never inside a map.
